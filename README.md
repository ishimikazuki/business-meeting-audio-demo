# 新規事業の会議音声：文字起こし・議事録作成デモ

AさんとBさんが新規事業を相談する、15分ちょうどの日本語デモ音声です。二種類のAI合成音声で新規作成した架空の会議で、実在人物の録音ではありません。冒頭でもAI合成音声と伝えています。

## 音声をダウンロード

[15分のデモ音声 MP3](audio/business-meeting-15min.mp3?raw=true)

約10.8MB、モノラル、24kHz、96kbps。GitHubの「Code」から「Download ZIP」を選ぶと、答え合わせもまとめて取得できます。

## 会話の内容

小規模飲食店の予約問い合わせを整理する新規事業を、事業企画担当のAさんと、顧客調査・製品担当のBさんが検討します。課題仮説、試験運用、料金案、予算、担当と期限、保留事項を含む全62発話です。実際の市場調査や経営判断の根拠としては使えません。

## 練習方法

音声だけを渡して全文の文字起こしと議事録を作成し、その後で答え合わせと比べてください。決定事項・担当・期限・保留事項、途中の予算案と最終決定を区別できるか確認できます。

- `audio/business-meeting-15min.mp3`：入力用の音声。
- `answers/script.txt`：音声生成に使った時刻付き台本。音声認識の結果ではありません。
- `answers/expected-minutes.md`：議事録の答え合わせ。

答え合わせは最初の入力に含めないでください。生成方法はOpenAIの音声合成です。声の高さを保って会話全体の速さを調整し、長い無音で尺を埋めず15分にしています。
